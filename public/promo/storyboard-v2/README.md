# 照着拍 · 原分镜与动态镜头说明

本版是 30 秒分镜预演。人物镜头以 AI 关键帧表示，不是已生成的连续真人动作。产品镜头使用实际浏览器截图，已知示例标识保留。原分镜的六段时间、文案与故事顺序保持一致。

| 时间 | 原定画面与本版安排 | 字幕 / 旁白文本 |
|---|---|---|
| 0–4 秒 | 一张窗边人像放在米白杂志版面，标题渐显；不在开场堆放功能页面。 | 喜欢这张，然后怎么拍？ |
| 4–8 秒 | 同一咖啡馆，人物坐在窗边，拿手机的人选择角度。用双人侧面关键帧标记待制作的动态镜头。 | 站哪里？手机怎么拿？光从哪边来？ |
| 8–14 秒 | 8–9.5 秒窗帘与桌面光线细节；9.5–14 秒实际产品光影图，依次突出窗户、被拍者、手机。 | 先找到光。 / 脸稍微转向窗边。 |
| 14–20 秒 | 14–17 秒交替呈现人物转脸与拍摄者选角度的关键帧；17–20 秒实际拍摄界面，保留参考缩略图与辅助线，再放大角色提示。 | 你调整取景，我调整动作。 |
| 20–25 秒 | 短暂照片定格，进入真实复拍页面；展示「动作自然一点」和下一张建议；23.6–25 秒用端杯看窗外的关键帧承接动作。 | 喜欢的留下，下一张只改一点。 |
| 25–30 秒 | 同一首页切换杂志版 / 笔记版，28 秒起留下名称和短文案。 | 照着拍，把怎么拍说清楚。 |

## 动态素材制作要求

统一人物与场景：以附带四格关键帧及原产品咖啡馆图片为连续性参考；白色亚麻衬衫、蓝色牛仔裤、短卷发人物；摄影者灰绿色衬衫、深色裤子；左侧窗户、深木桌、陶瓷咖啡杯、绿封面书、细花枝、墨绿墙。光线保持左侧入射。所有表演轻微自然。

1. **选角度，4 秒**：从双人侧面中景开始，拍摄者在两个相邻取景角度间轻微犹豫，手机竖持；被拍者安静坐着。固定机位或极轻推近。保持手机与双手的形状稳定。
2. **窗帘与窗光，约 2 秒**：从窗户细节关键帧开始，薄纱轻动，光落在桌面；杯子、书和花瓶不移动。无闪烁，无明显日照跳变。
3. **转脸与调整机位，约 3 秒**：人物向左侧窗户缓慢转脸，拍摄者轻移半步调整构图；只发生轻微动作，保留同一机位关系与家具位置。
4. **端杯看窗外，约 2 秒**：人物从桌上轻轻端起杯子，视线移向窗外；手指与杯把保持自然，杯子不变形。结束帧停留约半秒便于剪辑。

这些镜头需要图生视频能力或实际拍摄素材。当前工具完成的是关键帧生成、分镜预演、配乐和产品界面剪辑；连续人物动作尚未生成。

人物动态素材确定后，相机页面应使用同场景、同姿势的视频输入重新录制，再与拍后定格衔接。当前预演使用已保存的真实产品演示截图，保留原有示例标识。

## 配乐与素材

配乐为本片编写合成的轻柔器乐与少量快门声，无第三方歌曲采样，无人声旁白。预演片包含可直接阅读的文字，旁白文本见上表。对外介绍时请称本版为「分镜预演」，而非最终人物动态广告。
